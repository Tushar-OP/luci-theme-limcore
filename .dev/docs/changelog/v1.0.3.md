# v1.0.3

A fix release for floating notifications (toasts) that carry their own content
buttons or tables — most visibly the "New Firmware Available" notice on the
Overview page.

## Notifications

- Toasts no longer collapse into an empty pill. The close-button styles matched
  any classless `div` holding a `.btn`, meant for the wrapper of LuCI's Dismiss
  button. A notification whose body has a button of its own — the firmware
  notice's "Stop showing upgrade alerts" — matched too, so the whole message
  body was positioned absolutely in the corner and clipped by the toast,
  leaving only the icon and a close cross. The rule now applies to the last
  classless `div` only, which is where LuCI puts Dismiss.

- The toast icon sits next to the title. It was centered vertically, which on
  a tall toast left it floating halfway down beside the message body.

- Tables inside toasts are compact. They used the full page-table styling —
  large cells and headers — and a 420px toast squeezed them until labels broke
  over three lines and revision hashes split at the hyphen. They now use small
  text, tight cells flush with the message text, muted column headers and
  monospace version strings. On phones the table stays a table instead of the
  stacked card layout, and only long revision hashes are allowed to wrap.
  Toasts carrying a table are 480px wide on desktop.

- Action buttons inside a toast's message are drawn in the toast's own colour —
  a transparent button with a tinted border — instead of the opaque secondary
  button, get some space above them, and wrap cleanly on narrow screens.
